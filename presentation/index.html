Slide 2 — Layer 1 (examples/01_arrow.rs)

Apache Arrow: Columnar Memory, Zero-Copy & SIMD Kernels

cargo run --example 01_arrow
Columnar Buffer Layout

Contiguous typed buffers + separate validity bitmaps (NullBuffer), dictionary-encoded strings (Dictionary<Int32, Utf8>), and nested StructArrays.

Zero-Copy Slicing

batch.slice(offset, len) shares the exact physical Buffer pointer without allocating or copying values (orig_ptr + 8 == slice_ptr).

Vectorized Compute & IPC

Evaluates sub, gt_eq, filter_record_batch, lexsort_to_indices, and StreamWriter IPC framing over entire columns at once.

Code Snippet (examples/01_arrow.rs)
// Zero-copy slice of rows [1..4]
let sliced = batch.slice(1, 3);

// Vectorized subtraction: headroom = budget - latency
let headroom = sub(budget_col, lat_col)?;

// Vectorized boolean predicate filter
let breach_mask: BooleanArray = gt_eq(lat_col, budget_col)?;
let breached = filter_record_batch(&batch, &breach_mask)?;

// Top-3 sort via lexsort_to_indices + take_record_batch
let idx = lexsort_to_indices(&[SortColumn {
    values: batch.column_by_name("latency_ms").unwrap().clone(),
    options: Some(SortOptions { descending: true, nulls_first: false }),
}], Some(3))?;
let top3 = take_record_batch(&batch, &idx)?;

Slide 3 — Layer 2 (examples/02_parquet.rs • src/parquet_io.rs)

Apache Parquet on MinIO: Statistics, Bloom Filters & Pushdown

cargo run --example 02_parquet
1. ZSTD + Bloom Filters on MinIO

ParquetObjectWriter streams Arrow batches to s3://fdap-warehouse with ZSTD level 3, page-level stats, and Bloom filters on device_id & service.

2. Footer-Only S3 Range Read

ParquetObjectReader fetches only the footer bytes via HTTP Range GET to inspect row groups and column min/max statistics before reading data pages.

3. Three-Stage Read Pruning

Combines Row Group pruning (via stats), RowFilter late materialization (ArrowPredicateFn), and Column Projection (ProjectionMask).

Async Pushdown Reader (src/parquet_io.rs)
let reader = ParquetObjectReader::new(storage.as_object_store(), path)
    .with_file_size(head.size);
let mut builder = ParquetRecordBatchStreamBuilder::new(reader).await?;

// 1. Prune row groups where max(latency_ms) < threshold
selected_row_groups.retain(|&rg_idx| {
    if let Some(Statistics::Double(s)) = rg.column(lat_idx).statistics() {
        return s.max_opt().copied().unwrap_or(f64::MAX) >= threshold;
    }
    true
});

// 2. Push down RowFilter + ProjectionMask
let predicate = ArrowPredicateFn::new(pred_mask, move |batch| { ... });
builder = builder
    .with_row_groups(selected_row_groups)
    .with_row_filter(RowFilter::new(vec![Box::new(predicate)]))
    .with_projection(ProjectionMask::roots(&parquet_schema, cols));

Slide 5 — Layer 4 (examples/04_flight.rs • src/flight.rs)

Apache Arrow Flight: High-Speed gRPC Columnar Wire Transport

cargo run --example 04_flight
Flight RPC Protocol Endpoints (FdapFlightService)
  • get_flight_info: Plans SQL in DataFusion, encodes the output Arrow Schema and returns a Ticket.
  • do_get: Executes df.execute_stream() and streams Arrow IPC frames via FlightDataEncoderBuilder.
  • do_put: Decodes incoming FlightRecordBatchStream, writes a Parquet partition to MinIO, and updates DataFusion.
  • list_flights & do_action: Exposes catalog discovery, explain, seed_warehouse, and health checks.
Streaming do_get Implementation (src/flight.rs)
async fn do_get(
    &self,
    request: Request<Ticket>,
) -> Result<Response<Self::DoGetStream>, Status> {
    let sql = String::from_utf8(request.into_inner().ticket.to_vec())?;
    let df = self.engine.session_context().sql(&sql).await?;
    let schema = df.schema().inner().clone();

    let batch_stream = df.execute_stream().await?
        .map_err(|e| FlightError::ExternalError(Box::new(e)));

    let flight_data_stream = FlightDataEncoderBuilder::new()
        .with_schema(schema)
        .build(batch_stream)
        .map_err(|e| Status::internal(e.to_string()));

    Ok(Response::new(Box::pin(flight_data_stream)))
}

Repository Guide, Standalone Server & Flight CLI

1. Run Layer-by-Layer Examples
# Start local MinIO (or let FdapEngine auto-start it)
./scripts/minio.sh start

# Layer 1: Apache Arrow
cargo run --example 01_arrow

# Layer 2: Apache Parquet on MinIO
cargo run --example 02_parquet

# Layer 3: Apache DataFusion
cargo run --example 03_datafusion

# Layer 4: Apache Arrow Flight
cargo run --example 04_flight

# Full FDAP Query Engine Showcase
cargo run --example 05_fdap_query_engine
2. Run Standalone Server & Flight CLI
# Terminal 1: Start FDAP Flight Server on :50051
cargo run --bin fdap-server

# Terminal 2: Inspect MinIO warehouse catalog
cargo run --bin fdap-cli -- tables

# Execute SQL over Arrow Flight
cargo run --bin fdap-cli -- query \
  "SELECT region, COUNT(*) FROM telemetry GROUP BY region"

# Inspect DataFusion physical plan & pushdown
cargo run --bin fdap-cli -- explain \
  "SELECT device_id FROM telemetry WHERE latency_ms > 250.0"

# Stream live Arrow batches into MinIO via Flight DoPut
cargo run --bin fdap-cli -- ingest --table telemetry --rows 100
